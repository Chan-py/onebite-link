# Notion 스타일 디자인 테마

이 프로젝트의 UI는 [Notion](https://notion.so)의 미니멀하고 따뜻한 뉴트럴 톤 디자인 언어를 기준으로 한다. 화려한 장식보다 여백, 낮은 채도의 그레이, 절제된 그림자와 라운드를 우선한다. 컴포넌트를 새로 만들거나 스타일을 수정할 때 아래 토큰과 규칙을 그대로 적용한다.

## 레이아웃

- **본문 최대 너비**: `720px`, 페이지 중앙 정렬(`mx-auto`)
- **페이지 좌우 패딩**: 기본 `24px`(`px-6`), 데스크톱 와이드 레이아웃에서는 최대 `96px`까지 확장 가능
- **상단 헤더 높이**: `56~64px`, 하단에 `1px` 보더로 본문과 구분
- **사이드바 너비**: `240~260px`, 고정폭, 본문과 `1px` 보더로 구분
- **섹션 간 수직 여백**: `32px`(소), `48px`(중), `64px`(대)
- **그리드 갭**: 카드 그리드는 `16~24px` 갭, 컬럼 수는 컨테이너 폭에 따라 1~4열로 반응형 조정

## 컬러 팔레트

Notion 특유의 따뜻한 오프화이트/오프블랙 뉴트럴을 사용한다. 순수한 흑백(`#000`/`#fff`)은 피한다.

| 용도 | Light | Dark |
| --- | --- | --- |
| 본문 텍스트(primary) | `#37352F` | `#E9E9E7` |
| 보조 텍스트(secondary) | `rgba(55,53,47,0.65)` | `rgba(255,255,255,0.6)` |
| 옅은 보조 텍스트(placeholder) | `rgba(55,53,47,0.4)` | `rgba(255,255,255,0.4)` |
| 기본 배경 | `#FFFFFF` | `#191919` |
| 보조 배경(사이드바, hover) | `#F7F6F3` | `#202020` |
| 카드/입력 배경 | `#FFFFFF` | `#252525` |
| 보더 | `rgba(55,53,47,0.09)` | `rgba(255,255,255,0.09)` |
| 강조(링크, 포커스, 선택) | `#2383E2` | `#5AA7E4` |
| 강조 hover | `#0B6FCA` | `#7FBBEA` |
| 위험/삭제 | `#EB5757` | `#E06060` |

### Tailwind 매핑 가이드

Tailwind 기본 팔레트 중에는 `stone`이 Notion 그레이에 가장 가깝다(순수 회색인 `zinc`/`neutral`보다 따뜻함). 정확한 값이 필요하면 임의값(`bg-[#F7F6F3]`, `text-[#37352F]`)을 쓰고, 대략적인 톤이면 `stone-50~900`으로 대체 가능.

## 타이포그래피

- **폰트**: 시스템 폰트 우선 — `-apple-system, "Segoe UI", "Helvetica Neue", Arial, sans-serif` (이 프로젝트는 Geist Sans가 이미 있으므로 그대로 사용하되, 자간/굵기 규칙은 아래를 따름)
- **코드/모노스페이스**: `ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace`

| 요소 | 크기 | 굵기 | line-height | 비고 |
| --- | --- | --- | --- | --- |
| 페이지 타이틀(H1) | `40px / 2.5rem` | 700 | 1.2 | 자간 -0.01em |
| 섹션 타이틀(H2) | `30px / 1.875rem` | 600 | 1.3 | |
| 서브 타이틀(H3) | `24px / 1.5rem` | 600 | 1.35 | |
| 카드/블록 타이틀(H4) | `20px / 1.25rem` | 600 | 1.4 | |
| 본문 | `16px / 1rem` | 400 | 1.6 | 컬러: 본문 텍스트 primary |
| 보조 본문 | `14px` | 400 | 1.5 | 컬러: secondary |
| 캡션/메타 | `12px` | 500 | 1.4 | 컬러: secondary, 필요 시 uppercase + letter-spacing 0.04em |
| 버튼 라벨 | `14px` | 500 | 1 | |

- 문단 간 여백은 `12~16px`, 문단 내부 줄바꿈은 `1.6` 배수 유지
- 링크는 밑줄 대신 hover 시에만 underline 또는 accent 컬러로 표시

## 간격(Spacing) 스케일

`4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96` (px) 8배수 기반. 컴포넌트 내부 패딩은 4의 배수, 컴포넌트 간 여백은 8 이상을 사용.

## 라운드 & 그림자(Elevation)

| 요소 | radius |
| --- | --- |
| 인라인 요소(태그, 작은 아이콘 버튼) | `4~6px` |
| 버튼, 인풋, 셀렉트 | `6px` |
| 카드, 모달, 팝오버 컨테이너 | `8~10px` |
| 아바타/원형 아이콘 | `9999px`(full) |

| 레벨 | box-shadow | 용도 |
| --- | --- | --- |
| level 1 | `0 1px 2px rgba(0,0,0,0.08)` | 카드 hover, 낮은 강조 |
| level 2 | `0 3px 6px rgba(0,0,0,0.12), 0 9px 24px rgba(0,0,0,0.16)` | 팝오버, 드롭다운, 모달 |

그림자는 기본 상태에서는 거의 안 보이거나 없음 → hover/focus에서만 한 단계 올라가는 방식(그림자보다 보더 컬러 변화를 우선 사용).

## 버튼

- **Primary**: 배경 `#2F3437`(다크 그레이, 순검정 아님), 텍스트 흰색, radius `6px`, 패딩 `6px 12px`(높이 ~32px) 또는 `8px 16px`(높이 ~40px), font-size `14px` weight 500. hover 시 배경을 살짝 밝게(`#37352F` → `#454340` 등)
- **Secondary(outline)**: 배경 투명, 보더 `1px solid rgba(55,53,47,0.16)`, 텍스트 primary. hover 시 배경 `#F1F1EF`
- **Ghost/텍스트 버튼**: 배경/보더 없음, hover 시에만 배경 `#F1F1EF`, radius `6px`
- **Danger**: 텍스트 또는 배경에 위험 컬러(`#EB5757`) 사용, hover 시 배경 옅은 red(`#FFE2DD`)
- **아이콘 버튼**: 정사각 `28~32px`, radius `6px`, hover 배경 `#F1F1EF`
- 모든 버튼 전환은 `transition-colors duration-150 ease-in-out`

## 카드

- 보더 `1px solid` 보더 컬러, radius `8px`, 배경 카드 배경색, 패딩 `16px`
- 기본 상태는 그림자 없음(또는 level 1 아주 미세하게). hover 시 level 1 그림자 + 보더 컬러를 살짝 진하게, 필요하면 `translateY(-1px)` 정도의 미세한 리프트
- 커버 이미지가 있으면 카드 상단 라운드만 이미지에 적용(카드 radius와 동일하게)
- 카드 내부 구조: 아이콘/썸네일 → 타이틀(`14~16px`, weight 600, 1~2줄 clamp) → 메타/설명(`12~13px`, secondary, 2줄 clamp)
- 카드 그리드 갭은 레이아웃 섹션 참고(`16~24px`)

## 폼 & 인풋

- 높이 `36~40px`, 패딩 `8px 12px`, radius `6px`, 보더 `1px solid` 보더 컬러, 배경은 기본 배경색과 동일하거나 아주 옅은 회색
- placeholder는 옅은 보조 텍스트 컬러
- focus 시: 보더를 강조 컬러로 바꾸고, `box-shadow: 0 0 0 1px #2383E2` 정도의 얇은 링 추가(두꺼운 outline 지양)
- select, textarea도 동일한 규칙. textarea는 `line-height 1.6`, 최소 높이 `80px`
- label은 `14px` weight 500, 인풋과 `8px` 간격
- 에러 상태: 보더/텍스트를 위험 컬러로, 보조 설명 텍스트 `12px` 위험 컬러

## 사이드바 / 내비게이션

- 배경 보조 배경색(`#F7F6F3` / 다크 `#202020`)
- 아이템 패딩 `6px 8px`, radius `4~6px`, 아이콘-텍스트 간격 `8px`, 아이콘 크기 `16~18px`
- hover 시 배경 한 단계 진한 회색(`#EDEDEB`)
- active(선택됨) 상태는 accent 컬러 배경 또는 진한 배경 + weight 600 텍스트로 구분(현재 프로젝트처럼 진한 배경 pill도 허용)
- 섹션 구분은 여백(`16~24px`)으로, 구분선은 최소한으로만 사용

## 태그 / 배지

- 완전한 pill(`9999px`)보다 살짝 둥근 사각형(`4~6px`) 선호
- 패딩 `2px 8px`, font-size `12~14px`, weight 500
- 컬러는 위 "태그 컬러" 표 사용, 배경/텍스트 쌍을 항상 함께 적용(배경만 바꾸지 않음)

## 구분선 & 여백 구조

- `1px solid` 보더 컬러, 수직 마진 `16~24px`
- 과도한 구분선 사용 지양 — 여백만으로 섹션을 나눌 수 있으면 구분선 생략

## 테이블

- 헤더 배경 보조 배경색, 텍스트 `12~13px` weight 600 uppercase 또는 그대로
- 셀 패딩 `8px 12px`, 보더는 가로선 위주(`1px solid` 보더 컬러), 세로선은 최소화
- 행 hover 시 배경 보조 배경색
- 폰트 크기 본문과 동일(`14~16px`)

## 아이콘

- 라인 아이콘 기준 `16~20px`, stroke-width `1.5px` 내외
- 텍스트와 함께 쓸 때 아이콘 컬러는 secondary 텍스트 컬러와 맞춤(강조가 필요한 경우만 accent)
- 이모지 아이콘 혼용 가능(Notion 특유의 스타일) — 폴더/문서 등 엔티티 아이콘에 활용

## 모션

- 모든 hover/focus 전환은 `100~150ms ease-in-out`
- 큰 이동/스케일 애니메이션은 지양, 색상·그림자·보더 변화 위주의 미세한 트랜지션만 사용
- 페이지 전환/모달 등장 시에도 `150~200ms` 이내의 짧은 fade/slide만 허용

## 다크 모드

- 위 컬러 표의 Dark 컬럼을 그대로 사용하되, 다크 배경은 순검정이 아닌 `#191919`/`#202020` 계열 유지
- 보더는 `rgba(255,255,255,0.09)`처럼 저채도 화이트 알파로, 그림자보다 보더 대비로 레이어를 구분
- 강조 컬러(`accent`)는 다크에서 채도를 살짝 낮추고 밝기를 올린 버전(`#5AA7E4`) 사용
